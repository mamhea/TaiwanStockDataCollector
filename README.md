# Taiwan Stock Data Collector

台灣股票市場資料蒐集與分析系統。

## Project Overview

本專案使用 Python 蒐集台灣證券市場的歷史行情資料，並透過 SQLite 儲存，提供網頁化的股票查詢、統計分析及資料視覺化功能。

資料來源：

- TWSE（臺灣證券交易所）
- TPEx（證券櫃檯買賣中心）

## Features

- [ ] 上市股票每日行情蒐集
- [ ] 上櫃股票每日行情蒐集
- [ ] 最近五年歷史資料回補
- [ ] SQLite 資料庫管理
- [ ] 個股歷史行情查詢
- [ ] 股票排行榜
- [ ] 股價與成交量圖表
- [ ] 市場統計分析
- [ ] CSV / Excel 匯出
- [ ] 每日自動資料蒐集
- [ ] 電子郵件錯誤通知
- [ ] Streamlit 網頁儀表板
